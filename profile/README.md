**Gates of Olympus 1000 слот** — формат “pay anywhere” на поле 6×5 с каскадами: выигрышные символы исчезают и заменяются новыми. Это делает игру серийной: удачный момент может продолжиться цепочкой, а множители усиливают результат каскадной серии.

## ✨ Множители (x2–x1000)
